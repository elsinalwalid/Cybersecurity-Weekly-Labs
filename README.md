## Weekly Lab Structure

Each completed lab will include:

- **Objective:** What I aim to learn and accomplish.
- **Tools:** Software and technologies used.
- **Methodology:** Steps taken during the lab.
- **Evidence:** Screenshots, commands, and relevant outputs.
- **Findings:** Results and technical observations.
- **Lessons Learned:** Challenges, solutions, and key takeaways.
